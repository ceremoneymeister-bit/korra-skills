# Эмодзи-паки и стикерпаки Telegram

Скилл создаёт и ведёт паки через **Bot API отдельного бота пользователя**.
Владельцем пака становится сам человек: пак появляется у него в Telegram, а
бот только загружает файлы и вносит правки. Личный аккаунт и его сессии
скилл не трогает.

Всё делает `scripts/stickerpack.py` в папке этого скилла (Python ≥3.10,
Pillow; для видео — ffmpeg). Обычные места: Claude Code —
`~/.claude/skills/telegram-emoji-packs`, Codex, Cursor и OpenClaw —
`~/.agents/skills/telegram-emoji-packs`, Hermes и Korra — `${HERMES_SKILL_DIR}`.

```bash
SP="python3 <папка скилла>/scripts/stickerpack.py"
$SP setup                                   # первый запуск: бот и владелец
$SP info <set>                              # любой пак: имя из ссылки t.me/addemoji/<set>
$SP fetch <set> --out <каталог>             # файлы пака + meta.json
$SP sheet <каталог> --out sheet.png         # картинка-превью с номерами
$SP prepare <файлы…> --kind emoji --out <каталог>
$SP create <имя> --title "…" --kind emoji --from-set A --from-set B:1-10 --dry-run
$SP add <пак> --files <файлы…> --emoji 🔥 --at 2
$SP delete <пак> --pos 3,5-7
$SP order <пак> --order "21,5-20,1"         # неупомянутые уйдут в конец
$SP title <пак> "Новое название"
$SP cover <пак> --pos 1                     # эмодзи-пак; стикерпак — --file <обложка>
$SP emoji <пак> --pos 1 --emoji 🔥 --keywords "огонь,жара"
$SP preview <пак>                           # sheet.png и index.html по текущему порядку
```

`<пак>` — короткое имя; суффикс `_by_<бот>` скрипт добавляет сам. Позиции —
номера с 1, как на превью. Справка — `$SP <команда> --help`.

## Первый запуск

1. Человек создаёт **отдельного** бота в [@BotFather](https://t.me/BotFather)
   (`/newbot`) и нажимает у него «Старт». Имя бота войдёт в ссылку на каждый
   пак: `t.me/addemoji/<имя>_by_<бот>`, поэтому стоит выбрать понятное.
   Бота, которого уже опрашивает другая программа (например, бот самого
   агента), не используй: `setup` не сможет найти владельца, а в Korra и
   Hermes токен бота агента намеренно скрыт от команд.
2. Токен кладётся в переменную `STICKER_BOT_TOKEN` — **не в чат**:
   Korra — «Настройки → Ключи и доступы → Пользовательские ключи»;
   Hermes — файл `.env` в каталоге Hermes (`$HERMES_HOME`); Claude Code, Codex, Cursor, OpenClaw —
   переменная окружения или `--token-file <файл>`. Если токен всё же
   прислали в чат, предложи перевыпустить его в @BotFather (`/revoke`).
3. `$SP setup` показывает бота, находит владельца по «Старт» и сохраняет его
   id. Если боту писали несколько человек, `setup` покажет список — уточни у
   человека, какой из них он, и повтори с `--owner <id>`. Если никого не
   нашёл — попроси нажать «Старт» ещё раз.

## Порядок работы

1. **Источник.** Ссылка на пак — `info`, затем `fetch`. Архив выгрузки, где
   имена файлов похожи на `CAACAg…`, — это file_id: `identify <zip>` покажет
   исходный пак и позиции. Картинки и видео человека — `prepare --kind
   emoji|sticker`: обрежет прозрачные поля, впишет в нужный размер, видео
   переведёт в WEBM VP9; затем `validate`.
2. **Показ до сборки.** `sheet` по скачанным и подготовленным файлам и
   отправь картинку человеку: он выбирает номера, ты не угадываешь. Серии из
   нескольких плиток (надписи из 3–6 эмодзи) держи подряд и в исходном порядке.
3. **Создание.** `create … --dry-run` (проверка файлов и свободного имени),
   потом без него. Элементы добавляются по одному; повторный запуск
   продолжает с места остановки и не дублирует. `--from-set` можно повторять
   и брать часть пака: `B:1-10,15`.
4. **Правки** — `add`, `delete`, `order`, `title`, `cover`, `emoji`. После
   каждой скрипт сверяет пак с Telegram.
5. **Итог.** `preview` → отправь `sheet.png` и ссылку на пак
   (`https://t.me/addemoji/<имя>` или `addstickers`). Telegram обновляет
   открытый пак не сразу — пусть человек откроет его заново.

Для собственных файлов задавай `--emoji` по смыслу (иначе ⭐) и при желании
`emoji --keywords`: по ним эмодзи находится поиском. Обложка по умолчанию —
первый элемент. У эмодзи-пака `cover --pos N` делает обложкой любой элемент;
у стикерпака обложка — отдельный файл: `cover --file` (WEBP/PNG 100×100 до
128 КБ, TGS или WEBM 100×100 до 32 КБ).

## Что важно знать

| | Эмодзи (`addemoji`) | Стикеры (`addstickers`) |
|---|---|---|
| Размер | ровно 100×100 | одна сторона 512, другая ≤512 |
| Статика | WEBP/PNG | WEBP/PNG |
| Видео | WEBM VP9, ≤3 с, ≤30 fps, ≤256 КБ, без звука | то же |
| Анимация | TGS (Lottie) ≤64 КБ | то же |
| Сколько в паке | до 200 | до 120 |

- Создать эмодзи-пак может любой; **пользоваться** кастомными эмодзи в
  сообщениях можно только с Telegram Premium. Стикеры доступны всем.
- Форматы в одном паке можно смешивать. Название — до 64 символов,
  `@канал` в нём кликабелен. Короткое имя (адрес ссылки) потом не меняется —
  только новый пак.
- Чужие паки скрипт только читает. Собрать пак для себя из чужих — можно;
  если человек хочет выдать чужие рисунки за свои или убрать автора из
  названия, скажи об этом прямо: решение за ним, но автор может пожаловаться,
  и Telegram удалит пак.
- Удаление пака целиком (`delete-set`) — только по прямой просьбе удалить
  именно этот пак, с подтверждением полным именем.

Состояние каждого пака (порядок, id, исходники) — `<домашний каталог>/<имя>/`:
`STICKERPACKS_HOME`, иначе `$HERMES_HOME/sticker-packs`, иначе
`~/.sticker-packs`. Если пак меняли вручную в Telegram, скрипт предупредит и
возьмёт фактический порядок.

## Если что-то пошло не так

- Нет токена — шаг 2 первого запуска. `PEER_ID_INVALID` при создании —
  владелец не нажимал «Старт» у этого бота или id неверный.
- `setup`: «бот занят другой программой» — у бота уже есть webhook или его
  опрашивает другой процесс; нужен отдельный бот или `--owner <id>`.
- `STICKERSET_INVALID` в `info` — нет такого пака или опечатка в имени.
- `STICKER_VIDEO_LONG`, `STICKER_DIMENSIONS`, `file is too big` — файл не
  прошёл `prepare`/`validate`.
- Ограничения частоты (`retry_after`) скрипт выдерживает сам. Серия ошибок
  лимита — сделай паузу на час, не дроби запросы.

Проверка скрипта: `python3 -m pytest -q <папка скилла>/scripts` (без сети).
