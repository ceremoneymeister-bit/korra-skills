# Формат доски `board.html`

Доска — обычная HTML-страница с блоком `#board` размером с холст (например,
5760×3240 или выше). Скрипт открывает её в Chromium и снимает каждый элемент
отдельно, поэтому вёрстка может быть любой: абсолютные координаты, flex, SVG.

## Элементы

Рисуется всё с классом `el`, по одному, в порядке документа.

| Атрибут | Значение |
|---|---|
| `id` | уникальное имя; на него ссылаются камера и вуаль |
| `data-d` | сколько секунд рисуется элемент (по умолчанию 1) |
| `data-gap` | пауза перед ним, с (по умолчанию 0,1) |
| `data-mode` | `engine` (по умолчанию) — движок рисует контур, заливку и текст; `path` — для `<svg class="el">` с `<path>`: штрих проявляется по длине пути от начала к концу |
| `data-layer` | `0` — доска под камерой; `1` — финальная карточка поверх белой вуали, неподвижным планом `card_window` |

Подходящие элементы:
- `<img class="el" src="assets/icons/x.png">` — иконка на белом фоне;
- `<div class="el t">Текст</div>` — подпись рукописным шрифтом (`@font-face` из
  `assets/fonts/`); перенос — `<br>`, выравнивание по центру — `transform: translateX(-50%)`;
- `<svg class="el" data-mode="path"><path d="M … L …"/></svg>` — стрелки, рамки,
  подчёркивания. Наконечник — отдельные подпути после основной линии: они
  рисуются последними. Пунктир (`stroke-dasharray`) работает.

Время: `start` элемента = конец предыдущего + `data-gap`. На чтение подписи
закладывай 0,3 с на слово плюс 0,5 с. Подписи рисуются по 0,5–1 с, иконки —
по 0,6–1,5 с, длинные стрелки и рамки — по 1–2 с.

## Блок `#timeline`

```html
<script type="application/json" id="timeline">
{
  "canvas": [5760, 3240],
  "fps": 30,
  "end_hold": 2.0,
  "output": "video.mp4",
  "card_window": [2880, 1620, 5760],
  "previews": [{"name": "board", "y": 0, "w": 5760, "h": 3240}],
  "camera": [
    {"at": "start", "x": 1595, "y": 280, "w": 3000},
    {"at": "agent", "lead": 0.75, "move": 1.05, "x": 3550, "y": 1590, "w": 2200}
  ],
  "veil": {"at": "team-designer", "lead": 0.9, "dur": 0.7, "alpha": 0.95}
}
</script>
```

- `camera` — планы. Окно задаёт центр `x`, `y` и ширину `w`; высота — 16:9.
  Первый план (`"at": "start"`) действует с нуля. Каждый следующий начинает
  переезд за `lead` секунд до начала элемента `at` и длится `move` секунд.
  Рисование может начаться не раньше 70 % переезда, то есть `lead ≥ 0,7 × move`;
  если элемент у края кадра — `lead ≥ move`. Пауза `data-gap` у элемента
  должна вмещать `lead`, иначе камера тронется посреди предыдущей подписи.
- Масштаб на экране — `1920 / w`. Подпись кеглем 110 px при `w = 2300`
  займёт около 92 px, на общем плане `w = 6000` — около 35 px.
- `card_window` — неподвижный план для слоя 1. По умолчанию — весь холст.
- `veil` — когда доску накрывает белая вуаль перед слоем 1. По умолчанию —
  перед первым элементом слоя 1, непрозрачность 0,95.
- `previews` — какие области доски сохранить картинками при `preview`.
  Слой 1 всегда сохраняется своим окном в `preview-card.png`.

## Иконки: `sheets.json`

```json
{"grid": [3, 2],
 "sheets": {"s1.png": ["robot", "person", "cloud", "phone", "laptop", "server"]},
 "hand": "s5.png"}
```

Имена идут по ячейкам слева направо, сверху вниз. Деталь, залезшая в соседнюю
ячейку (антенна, хвост), остаётся у своей иконки: она относится к ячейке по
центру связной области. `hand` нужен, только если хочешь свою руку с маркером:
одна рука на белом фоне, кончик маркера — в левом нижнем углу картинки.
