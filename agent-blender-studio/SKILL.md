# Blender-студия для агента

Доведи вектор до готового предмета: форма → материал → свет → рендер → сайт
или кадры для ролика. Работает через терминал с Claude Code, Codex, Cursor,
Hermes, OpenClaw и Korra. Это набор скриптов и шаблонов, отдельный MCP не нужен.
Переменные окружения и платные API не требуются.

## Сначала результат

Выясни из поручения назначение и размер изображения, исходник и желаемый
материал. Обычные параметры выбери сам. Для первого просмотра хватит 640–960 px,
16–32 samples и одного материала. Покажи результат до дорогого финального рендера.
Не выдавай выполненную команду за удачный дизайн: осмотри силуэт, отверстия,
швы, блики, прозрачный край и отсутствие обрезки. Не публикуй сайт без поручения.

Нужны закрытые SVG-контуры; каждый path — отдельная герметичная фигура,
внутренние контуры остаются отверстиями. Переведи текст и обводки в контуры;
убери маски, фильтры, внешние ссылки и растровые вставки. Сохрани исходный SVG.
Нормализованный монохромный `source.svg` создаётся автоматически для веб-эффектов.
Многослойные цветные иллюстрации требуют предварительного упрощения.

## Подготовка

Найди установленный Blender. Скрипты проверены с Blender 5.2.2 на Linux x86_64.
Если его нет, установи отдельно в пользовательский каталог без прав администратора; установщик сверяет SHA-256 архива
с манифестом download.blender.org и не меняет PATH или настройки агента.
Для macOS/Windows установи Blender с официального сайта (Linux-архив не подходит).
Python вне Blender нужен версии 3.12+ для установщика, а для упаковки — Pillow.

```bash
python3 scripts/setup.py blender --version 5.2.2
python3 scripts/setup.py hdri --asset studio_small_09 --dir ./work/hdri
python3 -m venv ./work/venv
./work/venv/bin/python -m pip install Pillow==12.2.0
```

Все команды ниже запускаются из папки навыка; вместо `blender` подставь
найденный исполняемый файл. Пути работы задавай абсолютными, если запускаешь
из другой директории. HDRI необязателен: без него остаются три студийных
софтбокса и нейтральный мир. Установщик получает HDRI через API Poly Haven,
сохраняет рядом CC0-источник и контрольную сумму. Он не отправляет SVG в сеть.

## «Сделай объёмный логотип в нескольких материалах»

```bash
nice -n 10 blender -b -t 2 --python scripts/build_geo.py -- \
  --svg ./input.svg --out ./work/geo/foil.blend --preset foil
nice -n 10 blender -b ./work/geo/foil.blend -t 2 --python scripts/render.py -- \
  --out ./work/renders --materials graphite,gold,lime --width 960 --samples 32 \
  --hdri ./work/hdri/studio_small_09.hdr
./work/venv/bin/python scripts/pack.py --renders ./work/renders \
  --out ./work/site/assets --widths 640,960
```

- `foil` — ткань с давлением, закреплённая полоса по боковому контуру держит
  сварной шов, включая внутренние отверстия. `latex` — свободная мягкая оболочка.
- `extrude` — обычная экструзия; `--depth .07 --bevel .025` задают толщину и фаску.
- `--voxel .018` — размер сетки относительно высоты исходника. Более мелкая
  сетка сохраняет тонкие детали, но требует больше памяти. `--frames 44`,
  `--pressure 10` управляют симуляцией; не увеличивай давление для лечения дыр.
- `--shape 0` позволяет проверить одну фигуру, нумерация слева направо с нуля.
- Материалы: `graphite,gold,red,pastel,lime,pearl,holo`. Рендер использует Cycles,
  прозрачный фон и общий ортографический кадр. Свет можно менять в `render.py`.
- `--margin-x .3 --margin-y .35` — минимальные отступы в высотах исходника.
  Итоговый кадр автоматически расширяется по всем стадиям: число фигур не зашито.

Для сайта сначала согласуй тестовый кадр, затем рендери мастер `--width 3600
--samples 96`; упакуй `--widths 1600,2400,3600 --avif`. Pillow должен поддерживать
AVIF; без флага всегда есть WebP. Шаблоны используют WebP, AVIF можно подключить
к своему загрузчику из того же манифеста. Размеры выше мастера не создаются.
`data.png` / lossless WebP: R/G — нормали x/y из −1..1 в 0..1, B — высота по
`heightRange` в манифесте; альфа — маска. Это линейные данные, не цветная текстура.

## «Надуй знак по стадиям / подготовь кадры для ролика»

```bash
nice -n 10 blender -b -t 2 --python scripts/build_geo.py -- \
  --svg ./input.svg --out ./work/stages/geo.blend --preset latex \
  --frames 44 --stages 1,8,15,22,29,36,44
nice -n 10 blender -b ./work/stages/geo.blend -t 2 --python scripts/render.py -- \
  --out ./work/stage-renders --materials graphite,lime --width 960 --samples 32 --stages
./work/venv/bin/python scripts/pack.py --renders ./work/stage-renders \
  --out ./work/site/assets --widths 960
```

Это снимки настоящей симуляции с нарастающим давлением, а не масштабирование
готовой картинки. Рендер сохраняет кадр каждой фигуры отдельно; упаковка строит
атласы из общего охватывающего прямоугольника её стадий. Кадры можно передать
монтажному инструменту для обложек и роликов. Видеокодирование в навык не входит.

## «Оживи первый экран сайта»

Скопируй содержимое [web/](web/) в отдельную демо-папку проекта, а результат
`pack.py` — в её `assets/`. Открой по HTTP (не через file://):

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory ./work/site
```

- `ink.html` — жидкие чернила раскрывают объём, смещают плоский знак и рендер;
  материалы последовательно подключаются после загрузки страницы.
- `lacquer.html` — прозрачный лак с преломлением и бликами. Можно задать
  `material: 'graphite'` в конфиге; без него берётся первый материал манифеста.
- `breath.html` — каждая фигура надувается по своим стадиям. Нужен `--stages`.

Вызов в модуле страницы:

```javascript
import {start} from './studio.js';
start({selector: '#studio', manifest: './assets/manifest.json', effect: 'ink'});
```

Контейнер содержит `.hero-fallback` (обычный img с **заранее указанным** SVG,
alt и размерами) и `.hero-canvas`. Геометрия SVG, отступы, фигуры, материалы
и атласы читаются из манифеста; пути ассетов считаются относительно него.
Для фона передай `paper: [241,241,235]`, для плоских букв — `letterColor`.
CSS-фон должен совпадать с `paper`. На странице допускаются независимые контейнеры;
не монтируй два эффекта на один canvas. Настрой доступность текста и ссылок отдельно.

Сохрани fallback: без JS/WebGL2, при ошибке ассетов, reduced motion и потере
контекста SVG виден. Canvas не перехватывает касания, прокрутка свободна. В покое
нет кадров; при работе прозрачный холст, ранняя отсечка и scissor ограничивают
область композиции. Симуляция жидкости при активности обновляет свои буферы.
За экраном и в скрытой вкладке работа приостанавливается.

Проверь Chromium 320/390/768/1440, затем целевой телефон и WebKit: отсутствие
переполнения, касание меняет изображение, прокрутка работает; спустя 5–7 секунд
число `document.querySelector('#studio').studio.stats().draws` не растёт.
Проверь GPU loss/restore, reduced motion и отключённый JS. Автоматический скриншот
не доказывает плавность или расход батареи телефона. При нехватке GPU уменьши
мастер/атлас; fallback предпочтительнее сломанного эффекта.

## Ограничения и лицензии

Тонкие детали могут исчезнуть при voxel remesh; пересечения и открытые контуры
исправь до симуляции. Соседние фигуры не сталкиваются физически; это студия знаков
и небольших предметов, не универсальный моделлер персонажей. Форма может менять
силуэт при надувании. Не обещай точное совпадение с SVG без осмотра.

Число фигур определяется SVG, но ограничено памятью Blender и GPU браузера.
Атласы больше 8192 px упаковка отклоняет; браузер дополнительно проверяет свой
лимит. CPU-рендер может занять минуты и часы — ограничивай потоки и используй
`nice`, не запускай дорогой рендер рядом с критической сборкой.
